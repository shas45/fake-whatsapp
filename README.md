# 💬 Fake WhatsApp

A learning chat application built with Node.js, Express.js, MongoDB, Mongoose, EJS, and CSS.

This project was created while learning backend and full-stack web development concepts, with a focus on Express.js routing, MongoDB database operations, CRUD functionality, and server-side rendering with EJS.

## 🚀 Features

- Create new chats
- View existing chats
- Edit chat messages
- Delete chats
- MongoDB database integration
- Mongoose models and schemas
- Express.js routing
- EJS server-side rendering
- Basic form handling
- Custom error handling
- Simple responsive interface

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- EJS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose
